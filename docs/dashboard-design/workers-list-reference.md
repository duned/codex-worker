# Workers list visual reference

The [Workers list image](../mockups/workers-list-dark-reference.svg) is embedded in the dashboard design guide. This note preserves API field mappings; sample values are illustrative.

## API fields represented

Worker rows use display name and ID, connection, observation freshness, readiness, scheduling/drain state, reported capacity and active project IDs. Keep connection, readiness and freshness distinct. Unknown capacity stays unknown; occupied slots are not Server assignments.
